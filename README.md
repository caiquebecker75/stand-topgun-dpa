# Stand TOP GUN x DPA+

Proposta de cenografia: renders (Blender Cycles) e modelo 3D navegável (Three.js).

Créditos de terceiros:
- Capacete: "Fighter pilot helmet with attached oxygen mask", de Chenzoss (Sketchfab), CC BY 4.0.
- Caça: "Boeing F/A-18E/F Super Hornet", de andertan (Sketchfab), CC BY 4.0.
- Tubulação, quadro de força, eletrodutos, escada, extintores, caixote, galão, texturas e HDRI: Poly Haven (CC0).
- Fonte "TOP GUN": P. A. Vannucci (Alphabet & Type), freeware. `topgun-pt.ttf` é uma versão estendida pela 75 LAB com acentos, números e sinais.
